# v0.5.0 restricted polling pilot

Implemented, not execution verified. Local explicit approval is required because GitHub author identity is shared with the assistant connector. Approve-BridgeTask displays exact task and atomically queues its hash. Start-DoleviBridge-v05 polls local approvals every 30 seconds, consumes each before invoking the verified v0.4.2 runner which re-fetches and validates the GitHub task. No remote-only approval, automatic retry, merge or app edits. Run one worker only; stop with Ctrl+C. -Once processes current queue then exits. Child execution policy is inherited from the environment and may block execution; verify on Windows. Consumed files persist; failure/crash requires manual review. Local queue is not a security boundary against same-user software. No auto-update or background service. Test empty queue, approved pilot, modified body and duplicate prevention before enabling continuous polling.
